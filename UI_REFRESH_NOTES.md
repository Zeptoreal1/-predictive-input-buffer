# Aliou's Buffer — clean UI refresh

This version changes the **dashboard presentation only**. The prediction, assist, memory and practice engines are untouched.

## What's improved

- Graphite is the default theme for new installs (existing saved theme preferences remain available).
- Rebalanced window spacing, readable labels and status panel width.
- Cleaner buttons, calmer outlines, subtler selected navigation.
- Option rows now respond when you tap **anywhere on the row** — not only the switch.
- Header version text no longer collides with controls.
- Reduced the popup animation's bounce.
- All 14 original menu sections and all themes remain present.

## Build status

The repository still requires the Geode SDK and Geometry Dash to compile and test the mod. These changes have not been compiled or tested in-game here.

## Five feature ideas to choose for the next round

1. **Search all settings** — search by feature name with a jump-to-section result.
2. **Simple / Pro interface** — keep the everyday controls up front and tuck advanced tools away.
3. **Favourite controls** — pin your most-used settings to Home.
4. **Run insights** — clear visual summaries of saves, misses and trouble spots.
5. **Profile import/export** — portable presets for levels and game modes.
